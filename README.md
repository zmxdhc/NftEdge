# NftEdge

Watches cryptocurrency transactions and wallets for security alerts and notifications in real-time.

NftEdge is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Watches cryptocurrency transactions and wallets
- for security alerts and notifications
- in real-time

## Key Features

- Watches cryptocurrency transactions and wallets
- for security alerts and notifications
- in real-time

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftEdge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NftEdge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
